# Synthetic examples / 合成输入示例

[Project home](../README.md) · [Install & launch](../docs/getting-started/README.md)

- [chronic-care-demo.json](chronic-care-demo.json): small simulated clinical example.
- [chronic-care-flat-template.csv](chronic-care-flat-template.csv): flat CSV template illustrating fields.

These are example inputs, not real EHR exports, clinical ground truth or a complete ten-visit hospital dataset. Use the Admin intake validation/report to check a file before publishing cases. For full workflow demonstrations, use an appropriate validated synthetic cohort.

Do not replace these files with private patient records. Raw and derived hospital data belong in the platform's local Git-ignored `.data/` workflow.
